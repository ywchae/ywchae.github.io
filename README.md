# ywchae.github.io

Personal academic website of Yeonu Chae, served by GitHub Pages at https://ywchae.github.io/.

Plain HTML and CSS, no build step.

- `index.html` – the single page
- `style.css` – styles
- `assets/` – headshot and CV PDF

To update: edit the files, commit, and push to `main`. GitHub Pages redeploys within a minute or two.
